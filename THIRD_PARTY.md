# External tools

WireGuard Menu invokes separately installed Homebrew tools. Their source code and binaries are not bundled with this app, and their licenses are separate from this project's MIT license:

- [wireguard-tools](https://github.com/WireGuard/wireguard-tools), including `wg-quick`: [GPL-2.0](https://github.com/WireGuard/wireguard-tools/blob/master/COPYING).
- [wireguard-go](https://github.com/WireGuard/wireguard-go): [MIT](https://github.com/WireGuard/wireguard-go/blob/master/LICENSE).

This is an independent project, not an official WireGuard application.
